# Движение денежных средств (ДДС) - Веб-сервис

Веб-приложение для учета, управления и анализа поступлений и списаний денежных средств компании или частного лица.

## Технологии

- Backend: Django 5.2
- Database: SQLite (по умолчанию)
- Frontend: HTML, CSS (Bootstrap 5), JavaScript
- Дополнительные зависимости: django-crispy-forms, crispy-bootstrap5

## Установка и настройка

### 1. Установка зависимостей

Перед началом работы убедитесь, что у вас установлен Python 3.8 или выше.

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ваш-username/ваш-репозиторий.git
cd ваш-репозиторий
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
# Для Linux/MacOS:
source venv/bin/activate
# Для Windows:
venv\Scripts\activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```
(Если файла requirements.txt нет, установите зависимости вручную:)
```bash
pip install django django-crispy-forms crispy-bootstrap5
```

### 2. Настройка базы данных

1. Примените миграции:
```bash
python manage.py makemigrations
python manage.py migrate
```

2. (Опционально) Создайте суперпользователя для доступа к админ-панели:
```bash
python manage.py createsuperuser
```
Следуйте инструкциям для ввода имени пользователя, email и пароля.

3. Заполните начальные данные (статусы, типы операций, категории):
- Либо через админ-панель (/admin)
- Либо выполните fixtures (если они есть в проекте):
```bash
python manage.py loaddata initial_data.json
```

### 3. Запуск веб-сервиса

1. Запустите сервер разработки:
```bash
python manage.py runserver
```

2. Откройте в браузере:
- Основное приложение: http://127.0.0.1:8000/
- Админ-панель: http://127.0.0.1:8000/admin/

3. Для остановки сервера нажмите `Ctrl+C` в терминале.

## Начальная настройка приложения

После первого запуска:

1. Войдите в админ-панель (http://127.0.0.1:8000/admin/)
2. Добавьте необходимые справочники:
   - Статусы (Бизнес, Личное, Налог)
   - Типы операций (Пополнение, Списание)
   - Категории (привязываются к типам операций)
   - Подкатегории (привязываются к категориям)

## Работа с приложением

- Главная страница: просмотр всех записей с возможностью фильтрации
- Добавление новой записи: кнопка "Добавить запись"
- Редактирование: клик на "Изменить" в строке записи
- Удаление: клик на "Удалить" в строке записи

## Дополнительные настройки

Для production-режима:
1. Установите production-сервер (например, gunicorn + nginx)
2. Настройте файл `settings.py`:
   - DEBUG = False
   - Настройте ALLOWED_HOSTS
   - Настройте статические файлы
3. Используйте production-базу данных (PostgreSQL)
